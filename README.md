## 📌 عن المشروع (About The Project)
**NEXUS CMS** هو الحل الشامل لإدارة الكافيهات والمطاعم الحديثة. تم تصميم النظام لتلبية كافة احتياجات التشغيل اليومية، بداية من إدارة الطاولات، طلبات الموظفين، الورديات، وصولاً إلى نظام انتظار ذكي وطباعة حرارية متقدمة للتقارير والفواتير. والأهم من ذلك، يأتي مدمجاً بنظام **QR Code Menu** متكامل يتيح للعملاء تصفح المنيو بسهولة من هواتفهم.

## ✨ المميزات الرئيسية (Key Features)

*   📱 **قائمة طعام رقمية (QR Menu):** منيو إلكتروني ذكي وتفاعلي، سهل التحديث، يتيح للعملاء تصفح الأصناف وصورها عبر مسح رمز الاستجابة السريعة (QR Code) الموجود على الطاولة.
*   💻 **نظام نقاط البيع وإدارة الطلبات (POS):** واجهة سريعة وعصرية لإضافة الطلبات وتعديلها وإلغائها بكل سهولة.
*   🪑 **إدارة الطاولات المتقدمة:** تتبع حالة الطاولات (متاحة، مشغولة) مع دعم تقسيم الشيكات وإضافة طاولات جديدة لجلسات العمل.
*   🧑‍💼 **إدارة شاملة للموظفين:** تسجيل حضور وانصراف، سلفيات، وطلبات خاصة للموظفين بضغطة زر.
*   🖨️ **طباعة حرارية ذكية:** التقسيم التلقائي للطباعة (شيشة، بار، سحور، الخ) مع دعم طباعة إعلانات ترويجية مخصصة.
*   📊 **ورديات وتقارير دقيقة:** إغلاق الورديات بشكل آمن، حساب العجز والزيادة، وإصدار تقارير مبيعات شاملة.
*   ⏳ **نظام انتظار (Queue System):** تنظيم أدوار العملاء في أوقات الذروة.

## 🛠️ التقنيات المستخدمة (Tech Stack)
*   **Backend:** Python & Django Framework
*   **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
*   **Database:** SQLite / PostgreSQL (Ready)
*   **Architecture:** Modular App Design (sessions, orders, payments, employees, qr_menu, ...)
